# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-27

### Added
- **Bento Grid System**: High-contrast, modular UI with 28dp rounded surfaces, clean dividers, and typography-first hierarchy.
- **E-Ink Multi-Palette Engine**: Support for Pure Paper, Warm E-Paper, Charcoal Slate, and Brutalist Ink themes.
- **Distraction Shield & Notification Suppressor**: Background service (`NotificationSuppressorService`) to intercept alerts during deep work.
- **VIP Communication Whitelist**: Configurable allowlist for priority apps and urgent communication.
- **Executive Priorities Agenda**: Top 3 daily strategic objective manager on the home screen.
- **Digital Wellbeing & Focus Quotient**: 24-hour pickup tracking and executive productivity scoring.
- **Searchable App Drawer**: App category tags, custom naming, and daily screen time limits.
- **Android AppWidget**: Quick-toggle home screen widget for 1-tap focus activation.
- **GitHub Pages Interactive Documentation**: Complete guide website with interactive configuration walkthrough and permission helpers.
