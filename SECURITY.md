# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously. Because the Distraction-Free Launcher manages system notifications and app usage data locally, preserving device privacy is paramount.

If you discover a security vulnerability or sensitive data leak:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Please privately email the maintainers at `security@distractionfreelauncher.local` or open a confidential security advisory on GitHub.
3. Include details of the vulnerability, affected components, and step-by-step proof-of-concept instructions.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
